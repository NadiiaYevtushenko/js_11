📌 Повнофункціональний слайдер на чистому JavaScript

🔥 Опис проекту

Цей проект є розширеним слайдером, реалізованим за допомогою прототипів та класів у JavaScript. Він підтримує адаптивність, динамічне керування та різні методи взаємодії (тач-скрол, навігаційні кнопки, клавіатурне управління).

🎯 Основні можливості

Дві версії слайдера: на основі прототипів та класів.

Динамічне створення елементів управління (кнопки навігації, індикатори).

Гнучкі налаштування через конфігураційний об'єкт (інтервал автопрогортання, відображення індикаторів тощо).

Підтримка жестів (тач) і миші (перетягування слайдів).

Автопауза при наведенні миші на слайдер.

Адаптивний дизайн та підтримка всіх сучасних браузерів.

⚙️ Вимоги до виконання

Обидві версії (на прототипах та класах) мають бути розміщені у окремих гілках GitHub-репозиторію.

Чітка документація щодо налаштування та використання.

Повна кросбраузерна сумісність.

🚀 Встановлення та запуск

git clone https://github.com/your-repo/slider.git
cd slider
open index.html

📁 Структура проекту

slider/
│── assets/
│ ├── img/ # Зображення для слайдера
│── css/
│ ├── style.css # Основні стилі
│── js/
│ ├── carousel.js # Логіка слайдера (прототипи)
│ ├── swipe-carousel.js # Додано підтримку свайпів
│ ├── index.js # Головний скрипт
│── index.html # Головний HTML-файл

🛠 Використання

Відкрий index.html у браузері.

Використовуй кнопки вперед/назад, свайпи або клавіатуру (ArrowLeft, ArrowRight, Space).

Наведи мишку на слайдер – відбудеться автопауза.
